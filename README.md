# דרום אמריקה · אביב 2026

## העלאה ל-GitHub Pages
1. חלצי את קובץ ה-ZIP.
2. העלי את כל הקבצים שבתיקייה לשורש ה-Repository.
3. ודאי שהקובץ `index.html` נמצא בשורש.
4. ב-GitHub: Settings → Pages → Deploy from a branch → main / root.
5. המתיני דקה–שתיים ורענני את כתובת האתר.

## מה כלול
- כותרת ומיתוג חדשים
- מסלול מלא
- מדריך לכל יעד
- מלונות ואכסניות
- מסעדות ובתי קפה
- רשימת הכנות
- הערות שנשמרות במכשיר
- PWA בסיסית ועבודה אופליין לאחר טעינה ראשונה

המלצות לינה ואוכל הן רשימת פתיחה לתכנון. יש לבדוק זמינות, שעות פתיחה וביקורות עדכניות לפני הזמנה.
